# Phase gates

The design splits v1 into six phases; each ends at a gate the next phase depends on. A gate
report states what was built, how it was tested, open issues, decisions taken, and a demo
script a human can run. Gates that need people (counsel, auditors, an on-call rotation,
funded testnet credentials, vendor accounts) are marked **needs humans**: the code can be complete
while the gate is still open.

| Phase                          | Gate criterion (from the design)                                                                                                                      | Status                                                                                                                            | Report                                 |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| 0 · Foundations                | Spike result documented and a decision recorded                                                                                                       | Met; **ADR 0001 needs your sign-off** (the spike forced the fallback design)                                                      | [phase-0.md](phase-0.md)               |
| 1 · Ledger and accounts        | 10,000 simulated deposits and transfers reconcile with zero drift, including injected reorgs                                                          | **Met**: 10,000 movements, 272 reorgs, 0 drift                                                                                    | [phase-1.md](phase-1.md)               |
| 2 · Keys, policy and co-signer | A red-team agent cannot exceed any limit or pay a non-allowlisted address in 1,000 attempts                                                           | **Met**: 1,086 attempts, 0 leaks                                                                                                  | [phase-2.md](phase-2.md)               |
| 3 · Payments and x402          | End-to-end suite on Base Sepolia passes; external audit firms booked                                                                                  | Code complete, suite green on the simulated chain; **needs humans** (testnet credentials, audit booking)                          | [phase-3.md](phase-3.md)               |
| 4 · Escrow and streams         | No open high or critical audit findings                                                                                                               | Code complete, 100% contract coverage; **needs humans** (two audits)                                                              | [phase-4.md](phase-4.md)               |
